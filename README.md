# Roofer Next.js — Roofing Preview Sites

A reusable Next.js implementation of the Roofer-inspired roofing website, customized into ten independent business concept previews.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 and visit `/preview/<company-slug>`.

## Preview slugs

- roof-by-roof-exteriors
- bhinder-exteriors
- ebenezer-roofing

## Tech

Next.js 15, React 19, TypeScript, CSS, and Lucide icons. Company-specific configuration is in `lib/previewCompanies.ts`.
